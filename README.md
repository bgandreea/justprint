# SpoolMate

SpoolMate is a free batch printing software for Windows. It prints multiple PDFs, images, and text files at once, in the order you choose, without opening each file.

Add files or a folder, preview a page, then send the list to a printer. The files stay where they are.

## Print multiple PDFs at once

Use SpoolMate to print multiple PDF files in one run. Add the files, drop them on the window, or batch print all the PDFs in a folder. A mixed list works too: PDFs, images, and text files can be printed together.

Images can be PNG, JPEG, TIFF, BMP, GIF, or WebP. Text files can be TXT, CSV, or LOG.

Word, Excel, and PowerPoint files are not printed directly. Save those as PDF in their own app, then add the PDF.

## Batch print a folder

Batch print the supported files in a folder, including subfolders. SpoolMate builds a print list you can reorder, then prints that list from top to bottom.

Windows File Explorer only prints a small selection at a time. SpoolMate is for the longer job: bulk print a folder of PDFs, a stack of images, or a list of documents you want in a set order. Set copies, a page range, and one side or both sides before you start.

## Print settings

- Copies for each file, or one copy count for the whole list
- Collate, and repeat the list
- Page ranges such as `1-5, 8, 11-13`, or odd and even pages
- Portrait, landscape, or automatic orientation
- One side, or double-sided printing (long edge or short edge)
- Color or black and white
- Paper size and paper tray
- Fit, fill, actual size, or a scale percent
- Several pages on one sheet (2, 4, 6, 9, or 16), or a booklet
- Cover sheets, separator pages, headers, and footers

Pick any installed Windows printer. A test page is on the printer card.

## Download

Get the latest Windows build from [Releases](https://github.com/bgandreea/spoolmate/releases). Unzip the folder and run `SpoolMate.exe`. Keep the whole folder together.
